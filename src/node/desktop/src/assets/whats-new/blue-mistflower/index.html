New Features

  • Git worktrees: The Git pane's branch menu now lists the repository's worktrees. Choosing one opens it as a project, in this window or in a new session. More > New Worktree... checks a branch out into a new worktree, and More > Remove Worktree... deletes one. The New Branch dialog can also create its branch in a new worktree. A project opened from a worktree is labelled with the main checkout's name and the worktree directory, such as “rstudio [feature-x]”.
  • Fixed plot size: Plots can now be drawn at a fixed size in inches, centimeters, or pixels instead of the size of the Plots pane, from Plots > Fixed Size... or the size menu on the Plots pane toolbar. Resizing the pane scales the plot to fit without redrawing it, and exported plots default to the same size. Save Plot as Image can also save bitmaps at a chosen resolution (up to 600 DPI) without changing the plot's layout.
  • Hide columns in the data viewer: Columns can be hidden and shown again from the eye icons in the data viewer's summary panel, one at a time or all at once.
  • Show hidden objects: The Environment pane's List/Grid menu has new Show Hidden Objects and Show .Last.value toggles, so objects whose names begin with a dot (such as .data while debugging) can be listed.
  • Active tab highlight: The active document tab now has a bold label and a blue overline. This can be turned off in Tools > Global Options > General > Basic.
  • Look-alike character warnings: R diagnostics now warn about characters that look like ASCII but are not, such as a Cyrillic ‘c’, typographic quotes, or a no-break space, and about invisible characters such as a zero-width space.
  • More R diagnostics: R diagnostics now also catch several common mistakes: a repeated argument name in a function definition (function(x, x)), assigning to a constant (TRUE <- 1), a bare return with no parentheses, if (x<-1) where x < -1 was probably meant, library() calls for packages that aren't installed, and %05s-style zero-padded strings in sprintf(). Invalid characters, such as a pasted smart quote, now get a specific message instead of “unexpected token”. When argument checking is turned on in Tools > Global Options > Code > Diagnostics, diagnostics also flag duplicate named arguments, too many arguments, and an empty trailing argument such as c(1, 2, ).
  • Select Current Statement: Code > Select Current Statement (Ctrl+Alt+Shift+S) selects the whole R statement containing the cursor, including statements that span several lines.
  • Change spelling language: Edit > Change Spelling Language... switches the spelling dictionary in one step, and dictionary changes now apply to open documents without restarting RStudio.
  • Show a document's directory: Show Document's Directory on the document tab's context menu navigates the Files pane to the folder containing the document, including from a separate source window.
  • Terminal improvements: File paths printed in the Terminal pane (by git status, ls, or compiler errors, for example) open in the editor with Ctrl+Click (Cmd+Click on macOS), at the line and column when a file:line:column suffix is present. On macOS and Linux, rstudio <file>[:line[:column]] opens a file from the terminal. Ctrl+Shift+C and Ctrl+Shift+V now copy and paste, as in common terminal emulators.
  • ggplot2-aware pipe shortcut: Insert Pipe Operator (Ctrl+Shift+M) inserts + when the cursor is within a ggplot2 chain. This can be turned off in Tools > Global Options > Code > Editing.
  • Editor shortcuts in the Console: Customized editor keyboard shortcuts, such as Remove Word Left, now also apply to Console input.
  • Smooth scrolling: A new Use smooth scrolling option in Tools > Global Options > Code > Display animates source editor scrolling when the cursor moves off screen or when jumping to a line.
  • Markdown outline: The document outline is now available for plain Markdown (.md) documents.
  • Quarto render without preview: Rendering a Quarto document with the preview option set to “(No Preview)” now runs a one-time quarto render in a background job, instead of leaving a quarto preview server running.
  • Tutorial filter: The Tutorial pane has a filter box that narrows the list by package name, tutorial name, or title. Several words can be combined, such as a package name and a word from the tutorial's title.
  • XDG vimrc: Vim key mappings can now also be loaded from $XDG_CONFIG_HOME/vim/vimrc, or from ~/.config/vim/vimrc when that variable isn't set. RStudio checks it after ~/.rstudio-vimrc and ~/.vimrc.
  • Faster startup and smaller installs: RStudio Desktop starts faster and takes less disk space.
  • Posit Assistant updates: Updating Posit Assistant no longer requires closing other sessions that are using it, and Check for Posit Assistant Updates can reinstall the current version to repair a damaged installation.

Deprecated

  • Uninstall Posit Assistant: The Uninstall Posit Assistant command has been removed. To remove a downloaded Posit Assistant, delete its pai directory as described in the user guide.
