New Features

  • Split editor views: Open a second view of the same document, side by side or stacked, from View > Split Editor or the new button on the source editor toolbar. The two views share the document and its undo history, while scroll position, selection, and code folds stay independent, and the split is restored the next time the document is opened. Splitting applies to the source editor; the commands are unavailable while the visual editor is active.
  • Faster Data Viewer: Searching, filtering, and scrolling in the data viewer, and the Summary panel, are all faster.
  • Posit AI Pass: The Posit AI service is now called Posit AI Pass throughout the RStudio user interface.
  • Quarto 1.10: RStudio now bundles Quarto 1.10.

Deprecated

  • RPubs and ShinyApps.io: The RPubs and ShinyApps.io publishing destinations are now marked as deprecated ahead of their sunset. See the migration guide for moving to Posit Connect Cloud.
