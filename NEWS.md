## RStudio 2026.11.0 "Montauk Daisy" Release Notes

### New
- ([#12622](https://github.com/rstudio/rstudio/issues/12622)): RStudio Desktop now warns when a project asks for a different version of R than the one running (as recorded in its renv lockfile, or in the project file), and offers to switch to it. A version that is not installed is installed first, via [rig](https://github.com/r-lib/rig), in a background job, using the copy of rig bundled with RStudio. When the renv library of a project is empty, RStudio offers to run `renv::restore()`. The check can be disabled in Global Options > Packages.
- ([#19166](https://github.com/rstudio/rstudio/issues/19166)): Web hyperlink previews now show an Open in Browser icon alongside the URL.
- ([#19114](https://github.com/rstudio/rstudio/issues/19114)): Save Plot as Image can now compress TIFF images (with LZW, the default, or ZIP, each with or without a predictor where R supports it) and choose the quality of JPEG images. TIFFs were previously uncompressed, e.g. 36 MB for a 7 x 5 in plot saved at 600 DPI, and are now typically under 1 MB.
- ([#19142](https://github.com/rstudio/rstudio/issues/19142)): Reduced the work that blocks session startup: automatic Python discovery for reticulate now runs in the background, R and Quarto installation details are cached between launches, and SQL and Stan support loads on first use.
- ([#2846](https://github.com/rstudio/rstudio/issues/2846)): The editor gutter now marks lines that were added, changed, or removed since they were last staged or committed, for files in a Git repository. The markers update as you type; clicking one shows the previous version of those lines and offers to revert the change, and Tools > Version Control gains Next Change, Previous Change, and Revert Change at Cursor. The markers can be disabled in Global Options > Git/SVN.
- ([#19208](https://github.com/rstudio/rstudio/issues/19208)): Tools > Version Control > Show Changes Side by Side shows the version of the current file last staged or committed beside the document, read-only, with the changes between them highlighted on both sides, unchanged lines kept level, and scrolling in step. The document stays editable, and the comparison follows as you type.

### Fixed
- ([#19240](https://github.com/rstudio/rstudio/issues/19240)): The "RStudio has reduced background file operations" console notice is no longer printed again each time a suspended session is resumed or R is restarted; it is printed once per project session, and again when a restart first turns the reduction on.
- ([#19168](https://github.com/rstudio/rstudio/issues/19168)): RStudio now installs requested dependencies together in renv projects, allowing renv to resolve dependencies and use parallel installation even when individual package installation is enabled.
- ([#19165](https://github.com/rstudio/rstudio/issues/19165)): Improved vertical alignment of text buttons in the Packages toolbar and search fields on Windows.
- ([#19167](https://github.com/rstudio/rstudio/issues/19167)): The package tables in renv Snapshot and Restore dialogs now follow the dark theme.
- ([#19117](https://github.com/rstudio/rstudio/issues/19117)): Inline data frame output in R Markdown and Quarto documents, and the Data Viewer, now display runs of spaces in cell values as-is instead of collapsing them to a single space; the Data Viewer also shows embedded newlines and tabs escaped (`\n`, `\t`) rather than as a space.
- ([#19198](https://github.com/rstudio/rstudio/issues/19198)): Fixed an issue where loading matplotlib via reticulate failed with `TypeError: use() got an unexpected keyword argument 'warn'` on matplotlib 3.3 through 3.8 when a non-Agg backend was configured (e.g. via `MPLBACKEND`), which could also prevent TensorFlow and Keras from initializing in RStudio.
- ([#19185](https://github.com/rstudio/rstudio/issues/19185)): Fixed an issue where pressing Return on a comment line near the bottom of the editor, with "Continue comments on new lines" enabled, jumped the editor so the cursor sat near the top of the viewport instead of scrolling by one line. Shift+Return in the same configuration now scrolls the new line into view too.
- ([#19189](https://github.com/rstudio/rstudio/issues/19189)): Fixed an issue where, on R < 4.6, delayed bindings in the base environment were reported as plain values (and so were forced by the Environment pane when listing `package:base`).
- ([#19082](https://github.com/rstudio/rstudio/issues/19082)): Fixed an issue where console output slowed down, and the IDE could become unresponsive, as the console scrollback filled up -- most visibly when output alternated between stdout and stderr (e.g. `message()` and `cat()` in a loop).
- ([#19080](https://github.com/rstudio/rstudio/issues/19080)): Fixed an issue where the console could stall for many seconds while large amounts of stderr output with no colon in it (e.g. gert's `git_clone()` progress) arrived.
- ([#19214](https://github.com/rstudio/rstudio/issues/19214)): Fixed an issue where the Packages pane could show a stale package list (e.g. a blank Package Manager metadata column for a just-installed package) when two package-list refreshes overlapped.
- ([#19184](https://github.com/rstudio/rstudio/issues/19184)): Fixed an issue where commands that show a pane (e.g. View > Panes > Show Files) did nothing when the pane's column had been dragged shut with a column splitter; the column now reopens.
- ([#17196](https://github.com/rstudio/rstudio/issues/17196)): "Run All Chunks Above", "Run All Chunks Below", and "Run All" now run Python chunks, and switch the console between R and Python as needed, when chunk output is sent to the console rather than shown inline.
- ([#19059](https://github.com/rstudio/rstudio/issues/19059)): RStudio is now compatible with (and can build against) OpenSSL 4.x.
- ([#19079](https://github.com/rstudio/rstudio/issues/19079)): RStudio can now be built against a system Boost that was compiled as C++20 (e.g. with GCC 16, whose default is C++20): the build uses the compiler's default C++ standard when that is newer than the required minimum, and a newer standard can also be requested explicitly with `-DCMAKE_CXX_STANDARD=20`.
- ([#17215](https://github.com/rstudio/rstudio/issues/17215)): Fixed an issue where color previews in the editor shifted the cursor and bracket highlighting to the right at fractional zoom levels or display scaling.
- ([#19054](https://github.com/rstudio/rstudio/issues/19054)): Fixed an issue where saving a document could clear its spelling and diagnostic markers; the R Markdown toolbar now also picks up output format changes when autosave is enabled.
- ([#19056](https://github.com/rstudio/rstudio/issues/19056)): Fixed an issue where R diagnostics were very slow for large documents when the document or the working directory was on a slow filesystem (e.g. a network drive, or a Windows drive mounted within WSL), as the filesystem was consulted for every function call in the document.
- ([#19134](https://github.com/rstudio/rstudio/issues/19134)): [Accessibility] Modal dialogs no longer wrap keyboard focus from the last control back to the first (or from the first to the last with Shift+Tab). As with native browser dialogs, Tab past either end moves focus to the browser's own controls, or to the host page when RStudio is embedded in another page; the rest of the IDE remains unreachable while a dialog is open.
- ([#19130](https://github.com/rstudio/rstudio/issues/19130)): Fixed an issue where the R session could hang (Linux) or crash (macOS) when the Environment pane listed Python objects while reticulate was reporting the session's first Python error, e.g. as the Python REPL started.
- ([#19136](https://github.com/rstudio/rstudio/issues/19136)): Fixed an issue where RStudio Desktop on Linux with Wayland (e.g. Ubuntu with GNOME) started in a small window, marked as maximized, when it was last closed maximized; and where restoring a maximized window could make it a little smaller each time.
- ([#19138](https://github.com/rstudio/rstudio/issues/19138)): Fixed an issue where the Import Dataset preview showed a row-number column, and assigning it a type failed with "attempt to use zero-length variable name". The column-type menu also now opens after a column's type has been changed, and columns are wide enough for their type labels.
- ([#19222](https://github.com/rstudio/rstudio/issues/19222)): Fixed an issue where, after changing the help font size in Global Options > Appearance and clicking Apply, a later change to the editor or help font size in the same dialog could be lost.
- ([#19141](https://github.com/rstudio/rstudio/issues/19141)): [Accessibility] The separator after the Posit Assistant button in the main toolbar is now marked as decorative, so screen readers skip it.
- ([#19139](https://github.com/rstudio/rstudio/issues/19139)): [Accessibility] The banner and main landmarks are no longer nested inside the page-wide application landmark; the application role now covers only the pane area, inside the main landmark.
- ([#19151](https://github.com/rstudio/rstudio/issues/19151)): [Accessibility] Pane splitters now report their position to screen readers (`aria-valuenow`), as a percentage from the left or top edge, and update it as the panes are resized.
- ([#19146](https://github.com/rstudio/rstudio/issues/19146)): [Accessibility] The RStudio logo in the RStudio Server header now has alt text ("RStudio", or "Posit Workbench" when it links to the Workbench home page), so screen readers no longer find the banner landmark empty.
- ([#19156](https://github.com/rstudio/rstudio/issues/19156)): [Accessibility] The Files pane's select-all checkbox now carries its accessible name ("Select all files") itself, rather than through an `aria-label` on its `<label>`, where ARIA does not permit it.
- ([#19169](https://github.com/rstudio/rstudio/issues/19169)): [Accessibility] The Files pane's checkbox column header is no longer empty: it now has text that only screen readers see ("Selected").
- ([#19170](https://github.com/rstudio/rstudio/issues/19170)): [Accessibility] Sortable column headers (in the Files pane, Git and SVN changelists, Environment grid view, and the Keyboard Shortcuts and Addins dialogs) are now exposed to screen readers as column headers that report their sort direction, with the sort control as a button inside the header. The Files pane's file-type column header is now named "File type".
- ([#19173](https://github.com/rstudio/rstudio/issues/19173)): [Accessibility] Tables that keep their header fixed while the body scrolls (the Files, Environment grid view, Packages and Connections panes, the object explorer, and the Modify Keyboard Shortcuts, Browse Addins, renv and Packrat dialogs) are now exposed to screen readers as one table, so moving through a cell announces its column header.
- ([#19176](https://github.com/rstudio/rstudio/issues/19176)): [Accessibility] The icon before editor status bar messages, such as "Copilot: No completions available.", now has alt text naming the message type ("Information", "Warning", or "Error"). The loading spinner shown while a notebook renders is marked as decorative.
- ([#19172](https://github.com/rstudio/rstudio/issues/19172)): [Accessibility] The fade at the left edge of a scrolled path in the Files pane and file dialogs is now marked as decorative. It is also now shown only while the path is scrolled, at the visible left edge, so it no longer covers the first folder (e.g. after focus moves to it) or blocks clicks on it.
- ([#19181](https://github.com/rstudio/rstudio/issues/19181)): [Accessibility] Columns hidden by a zoom command (e.g. Zoom Left / Center Column, Zoom Console, Zoom Sidebar), or dragged shut with a column splitter, are now inert: screen readers no longer find their panes, and Tab and clicks no longer reach their controls. When a zoom hides the pane that has keyboard focus, focus moves into the zoomed pane; when a splitter drag or a window resize shuts the column that has focus, focus moves to the widest remaining column.
- ([#19183](https://github.com/rstudio/rstudio/issues/19183)): [Accessibility] Focus Next Pane (F6) and Focus Previous Pane (Shift+F6) no longer switch the Console pane to its Console tab; the selected tab, such as Terminal, stays selected and gets focus.
- ([#19191](https://github.com/rstudio/rstudio/issues/19191)): [Accessibility] Focus Next Pane (F6) and Focus Previous Pane (Shift+F6) now reach the sidebar when it is showing, and skip it when it is hidden; F6 no longer gets stuck on the bottom-right pane.
- ([#19199](https://github.com/rstudio/rstudio/issues/19199)): [Accessibility] When the user interface language is set to French, the page's language (`lang`) is now French too, so screen readers read the interface with a French voice.
- ([#13204](https://github.com/rstudio/rstudio/issues/13204)): In the Pastel On Dark theme, the current match of Find in the editor is now highlighted in amber; the theme's selection colour was too faint against its background to pick a match out by.
- ([#19223](https://github.com/rstudio/rstudio/issues/19223)): [Accessibility] Added accessible names to several Global Options controls that were missing them.
- ([#19207](https://github.com/rstudio/rstudio/issues/19207)): [Accessibility] The History pane's lists are now named ("Console History", "Console History Search Results", "Console History Context"), and its search-results and context views are inert when not shown, so Tab no longer reaches their hidden Back and Done buttons. Switching between these views no longer slides them when *Reduce user interface animations* is on. The History, Markers, and Find in Files lists are now exposed to screen readers as listboxes, so moving or extending the selection with the arrow keys while the list has focus announces the current item and whether it is selected; file names and timestamps that head a group of items are read as the items' descriptions.
- ([#19244](https://github.com/rstudio/rstudio/issues/19244)): [Accessibility] In the Connections pane, the icon-only columns of the connection list have hidden header text ("Type", "Explore"), connection type and object type icons have alt text, and pressing Enter on a table in the object browser opens it in the data viewer, as clicking its View table icon does. In the object browser tree, nested items are grouped under their parent item and the expand/collapse arrows are hidden from screen readers, which already announce whether an item is expanded.
- ([#15965](https://github.com/rstudio/rstudio/issues/15965)): Fixed an issue where configuring with `-DRSTUDIO_USE_SYSTEM_DEPENDENCIES=ON` failed. Dependencies that an installed package cannot provide (Hunspell, dtl and websocketpp) are now always fetched, and individual dependencies can be excluded with `-DRSTUDIO_USE_SYSTEM_<NAME>=OFF` (e.g. `-DRSTUDIO_USE_SYSTEM_YAML_CPP=OFF`).

### Deprecated / Removed
- ([#19041](https://github.com/rstudio/rstudio/issues/19041)): Removed the "What's New" window from RStudio Desktop, along with its **Help** > **What's New** command, its preference, and the `RSTUDIO_DISABLE_WHATS_NEW` environment variable. Use **Help** > **Release Notes** to see what changed in a release.
