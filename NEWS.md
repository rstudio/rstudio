## RStudio 2026.11.0 "Montauk Daisy" Release Notes

### New
- ([#12622](https://github.com/rstudio/rstudio/issues/12622)): RStudio Desktop now warns when a project asks for a different version of R than the one running (as recorded in its renv lockfile, or in the project file), and offers to switch to it. A version that is not installed is installed first, via [rig](https://github.com/r-lib/rig), in a background job; rig itself is downloaded when it is not already available. When the renv library of a project is empty, RStudio offers to run `renv::restore()`. The check can be disabled in Global Options > Packages.
- ([#19114](https://github.com/rstudio/rstudio/issues/19114)): Save Plot as Image can now compress TIFF images (with LZW, the default, or ZIP, each with or without a predictor where R supports it) and choose the quality of JPEG images. TIFFs were previously uncompressed, e.g. 36 MB for a 7 x 5 in plot saved at 600 DPI, and are now typically under 1 MB.
- ([#19142](https://github.com/rstudio/rstudio/issues/19142)): Reduced the work that blocks session startup: automatic Python discovery for reticulate now runs in the background, R and Quarto installation details are cached between launches, and SQL and Stan support loads on first use.

### Fixed
- ([#19195](https://github.com/rstudio/rstudio/pull/19195)): Fixed an issue where loading matplotlib via reticulate failed with `TypeError: use() got an unexpected keyword argument 'warn'` on matplotlib 3.3.0 and newer, which could also prevent TensorFlow and Keras from initializing in RStudio.
- ([#19185](https://github.com/rstudio/rstudio/issues/19185)): Fixed an issue where pressing Return on a comment line near the bottom of the editor, with "Continue comments on new lines" enabled, jumped the editor so the cursor sat near the top of the viewport instead of scrolling by one line. Shift+Return in the same configuration now scrolls the new line into view too.
- ([#19189](https://github.com/rstudio/rstudio/issues/19189)): Fixed an issue where, on R < 4.6, delayed bindings in the base environment were reported as plain values (and so were forced by the Environment pane when listing `package:base`).
- ([#19082](https://github.com/rstudio/rstudio/issues/19082)): Fixed an issue where console output slowed down, and the IDE could become unresponsive, as the console scrollback filled up -- most visibly when output alternated between stdout and stderr (e.g. `message()` and `cat()` in a loop).
- ([#19080](https://github.com/rstudio/rstudio/issues/19080)): Fixed an issue where the console could stall for many seconds while large amounts of stderr output with no colon in it (e.g. gert's `git_clone()` progress) arrived.
- ([rstudio/rstudio-pro#13167](https://github.com/rstudio/rstudio-pro/issues/13167)): Fixed an issue where the Packages pane could show a stale package list (e.g. a blank Package Manager metadata column for a just-installed package) when two package-list refreshes overlapped.
- ([#17196](https://github.com/rstudio/rstudio/issues/17196)): "Run All Chunks Above", "Run All Chunks Below", and "Run All" now run Python chunks, and switch the console between R and Python as needed, when chunk output is sent to the console rather than shown inline.
- ([#19059](https://github.com/rstudio/rstudio/issues/19059)): RStudio is now compatible with (and can build against) OpenSSL 4.x.
- ([#19079](https://github.com/rstudio/rstudio/issues/19079)): RStudio can now be built against a system Boost that was compiled as C++20 (e.g. with GCC 16, whose default is C++20): the build uses the compiler's default C++ standard when that is newer than the required minimum, and a newer standard can also be requested explicitly with `-DCMAKE_CXX_STANDARD=20`.
- ([#17215](https://github.com/rstudio/rstudio/issues/17215)): Fixed an issue where color previews in the editor shifted the cursor and bracket highlighting to the right at fractional zoom levels or display scaling.
- ([#19054](https://github.com/rstudio/rstudio/issues/19054)): Fixed an issue where saving a document could clear its spelling and diagnostic markers; the R Markdown toolbar now also picks up output format changes when autosave is enabled.
- ([#19056](https://github.com/rstudio/rstudio/issues/19056)): Fixed an issue where R diagnostics were very slow for large documents when the document or the working directory was on a slow filesystem (e.g. a network drive, or a Windows drive mounted within WSL), as the filesystem was consulted for every function call in the document.
- ([#19134](https://github.com/rstudio/rstudio/issues/19134)): [Accessibility] Modal dialogs no longer wrap keyboard focus from the last control back to the first (or from the first to the last with Shift+Tab). As with native browser dialogs, Tab past either end moves focus to the browser's own controls, or to the host page when RStudio is embedded in another page; the rest of the IDE remains unreachable while a dialog is open.
- ([#19130](https://github.com/rstudio/rstudio/issues/19130)): Fixed an issue where the R session could hang (Linux) or crash (macOS) when the Environment pane listed Python objects while reticulate was reporting the session's first Python error, e.g. as the Python REPL started.
- ([#19141](https://github.com/rstudio/rstudio/issues/19141)): [Accessibility] The separator after the Posit Assistant button in the main toolbar is now marked as decorative, so screen readers skip it.
- ([#19139](https://github.com/rstudio/rstudio/issues/19139)): [Accessibility] The banner and main landmarks are no longer nested inside the page-wide application landmark; the application role now covers only the pane area, inside the main landmark.
- ([#19151](https://github.com/rstudio/rstudio/issues/19151)): [Accessibility] Pane splitters now report their position to screen readers (`aria-valuenow`), as a percentage from the left or top edge, and update it as the panes are resized.
- ([#19146](https://github.com/rstudio/rstudio/issues/19146)): [Accessibility] The RStudio logo in the RStudio Server header now has alt text ("RStudio", or "Posit Workbench" when it links to the Workbench home page), so screen readers no longer find the banner landmark empty.
- ([#19156](https://github.com/rstudio/rstudio/issues/19156)): [Accessibility] The Files pane's select-all checkbox now carries its accessible name ("Select all files") itself, rather than through an `aria-label` on its `<label>`, where ARIA does not permit it.
- ([#19169](https://github.com/rstudio/rstudio/issues/19169)): [Accessibility] The Files pane's checkbox column header is no longer empty: it now has text that only screen readers see ("Selected").
- ([#19170](https://github.com/rstudio/rstudio/issues/19170)): [Accessibility] Sortable column headers (in the Files pane, Git and SVN changelists, Environment grid view, and the Keyboard Shortcuts and Addins dialogs) are now exposed to screen readers as column headers that report their sort direction, with the sort control as a button inside the header. The Files pane's file-type column header is now named "File type".
- ([#19173](https://github.com/rstudio/rstudio/issues/19173)): [Accessibility] Tables that keep their header fixed while the body scrolls (the Files, Environment grid view, Packages and Connections panes, the object explorer, and the Modify Keyboard Shortcuts, Browse Addins, renv and Packrat dialogs) are now exposed to screen readers as one table, so moving through a cell announces its column header.
- ([#19176](https://github.com/rstudio/rstudio/issues/19176)): [Accessibility] The icon before editor status bar messages, such as "Copilot: No completions available.", now has alt text naming the message type ("Information", "Warning", or "Error"). The loading spinner shown while a notebook renders is marked as decorative.
- ([#19172](https://github.com/rstudio/rstudio/issues/19172)): [Accessibility] The fade at the left edge of a scrolled path in the Files pane and file dialogs is now marked as decorative. It is also now shown only while the path is scrolled, at the visible left edge, so it no longer covers the first folder (e.g. after focus moves to it) or blocks clicks on it.

### Deprecated / Removed
- ([#19041](https://github.com/rstudio/rstudio/issues/19041)): Removed the "What's New" window from RStudio Desktop, along with its **Help** > **What's New** command, its preference, and the `RSTUDIO_DISABLE_WHATS_NEW` environment variable. Use **Help** > **Release Notes** to see what changed in a release.

### Dependencies
- Electron 44.7.2

- Quarto 1.10.19
