## RStudio 2026.12.0 "Parrot Balsam" Release Notes

### New
- ([#12622](https://github.com/rstudio/rstudio/issues/12622)): RStudio Desktop now warns in the Console when a project asks for a different version of R than the one running (as recorded in its renv lockfile, or in the project file), and offers to switch to it. A version that is not installed can be installed first, via [rig](https://github.com/r-lib/rig), in a background job, using the copy of rig bundled with RStudio, into a folder confirmed (or changed) before the installation starts; a nearby installed version is offered as an alternative. When the renv library of a project is empty, RStudio offers to run `renv::restore()`. The check can be disabled in Global Options > Packages.
- ([#19166](https://github.com/rstudio/rstudio/issues/19166)): Web hyperlink previews now show an Open in Browser icon alongside the URL.
- ([#19114](https://github.com/rstudio/rstudio/issues/19114)): Save Plot as Image can now compress TIFF images (with LZW, the default, or ZIP, each with or without a predictor where R supports it) and choose the quality of JPEG images. TIFFs were previously uncompressed, e.g. 36 MB for a 7 x 5 in plot saved at 600 DPI, and are now typically under 1 MB.
- ([#19142](https://github.com/rstudio/rstudio/issues/19142)): Reduced the work that blocks session startup: automatic Python discovery for reticulate now runs in the background, R and Quarto installation details are cached between launches, and SQL and Stan support loads on first use.
- ([#2846](https://github.com/rstudio/rstudio/issues/2846)): The editor gutter now marks lines that were added, changed, or removed since they were last staged or committed, for files in a Git repository. The markers update as you type; clicking one shows the previous version of those lines and offers to revert the change, and Tools > Version Control gains Next Change, Previous Change, and Revert Change at Cursor. The editor's status bar counts the changes, says which one the cursor is on, and has buttons to step through them. Each file in the Git pane also gets a button that opens it at its first change. The markers can be disabled in Global Options > Git/SVN.
- ([#19208](https://github.com/rstudio/rstudio/issues/19208)): Tools > Version Control > Show Changes Side by Side, also a toggle on the editor toolbar, shows the version of the current file last staged or committed beside the document, read-only, with the changes between them highlighted on both sides, unchanged lines kept level, and scrolling in step. Headers name the two sides (before: the index; after: the working tree). The document stays editable, and the comparison follows as you type; clicking a change marker offers to revert that change.

### Fixed
- ([#15965](https://github.com/rstudio/rstudio/issues/15965)): Fixed several issues that prevented building with `-DRSTUDIO_USE_SYSTEM_DEPENDENCIES=ON`, where Hunspell, RapidJSON, utf8cpp, GTest and libgit2 were not found or not linked. Hunspell, dtl and websocketpp, which an installed package cannot provide, are now always fetched, and individual dependencies can be excluded with `-DRSTUDIO_USE_SYSTEM_<NAME>=OFF` (e.g. `-DRSTUDIO_USE_SYSTEM_YAML_CPP=OFF`). Thanks to [@Flamefire](https://github.com/Flamefire).
- ([#19362](https://github.com/rstudio/rstudio/issues/19362)): Fixed an issue where the console could show the warning "converting NULL pointer to R NULL" from `rs_getBrowserEnv` shortly after a session started.
- ([#19406](https://github.com/rstudio/rstudio/issues/19406)): Fixed an issue where Reformat Selection did nothing in an unsaved document when Air was the code formatter. Unsaved documents now also use the open project's `air.toml`.
- ([#19386](https://github.com/rstudio/rstudio/issues/19386)): Fixed an issue where the Terminal's right-click menu on Windows and Linux Desktop listed Ctrl+C and Ctrl+V for Copy and Paste, which the terminal sends to the shell, instead of Ctrl+Shift+C and Ctrl+Shift+V.
- ([#19367](https://github.com/rstudio/rstudio/issues/19367)): C and C++ diagnostics and completions no longer stop after the first 19 errors in a file; RStudio now passes `-ferror-limit=0` to libclang. Extra flags can be supplied through a `compile_flags.txt` file (one argument per line, the clangd convention) in the source file's directory or, within a project, any parent up to the project directory; these are appended to the generated flags, so they can override them.
- ([#17182](https://github.com/rstudio/rstudio/issues/17182)): Fixed inconsistent nesting of section headers inside braces (e.g. the body of an `if`) in the document outline. A section header is now nested by its heading level as if the braces were not there: a header following one of the same level is shown beside it rather than under it, and a header inside braces no longer cuts short an enclosing function.
- ([#19416](https://github.com/rstudio/rstudio/issues/19416)): Fixed an issue where the link to the content in the republish dialog led to a blank or 404 page on Posit Connect 2026.01.0 and later.
- ([#19428](https://github.com/rstudio/rstudio/issues/19428)): Fixed an issue where the Configure Application command opened a blank or 404 page on Posit Connect 2026.01.0 and later.
- ([#19390](https://github.com/rstudio/rstudio/issues/19390)): Fixed an issue where choosing Select All from the Terminal's right-click menu in RStudio Desktop did not select the terminal's output.
- ([#19427](https://github.com/rstudio/rstudio/issues/19427)): Fixed an issue where the web file dialogs (e.g. Files > More > Copy To...) did nothing when Save was clicked with an empty file name, and reported "Illegal name" instead of navigating to the parent folder when the `..` row was selected or a relative path such as `..` or `../sub/` was typed.
- ([#19415](https://github.com/rstudio/rstudio/issues/19415)): Fixed an issue where the Insert Pipe Operator command (Ctrl+Shift+M) inserted `+` after any call to a function whose name starts with `theme_` (or `scale_`, `stat_`, and the other ggplot2 prefixes), even outside a ggplot2 chain. Such calls now only count as part of a ggplot2 chain when joined to a neighbor with `+` (or patchwork's `&`).
- ([#19381](https://github.com/rstudio/rstudio/issues/19381)): [Accessibility] Fixed an issue where screen readers announced the `manipulate()` picker, checkbox, and slider controls without their labels, and the slider without its role or value. Pressing Home or End on the slider now also redraws the plot.
- ([#19378](https://github.com/rstudio/rstudio/issues/19378)): [Accessibility] Fixed an issue where the Tutorial pane's links to install `learnr` or update `shiny` were named "click here" for screen reader and voice control users. The links now read "install the learnr package" and "install the shiny package" (or "update the shiny package" when an older version is installed).
- ([#19381](https://github.com/rstudio/rstudio/issues/19381)): [Accessibility] Fixed an issue where screen readers announced the "Engine path" and "Engine options" fields in the chunk options popup by their "Default" placeholder instead of their labels, and the engine path's browse button only as "...". The button is now named "Select Engine".
- ([#19381](https://github.com/rstudio/rstudio/issues/19381)): [Accessibility] Fixed an issue where screen readers announced the venv or condaenv packages field on the New Quarto Project pages by its "(none)" placeholder. The field is now named "Packages to install in the environment".
- ([#19381](https://github.com/rstudio/rstudio/issues/19381)): [Accessibility] Fixed an issue where screen readers announced the second field in the first row of a New Connection snippet (e.g. "Port" beside "Server") without its label.
- ([#19381](https://github.com/rstudio/rstudio/issues/19381)): [Accessibility] Fixed an issue where screen readers announced the text fields in custom project templates (from a package's `inst/rstudio/templates/project` or `~/.R/rstudio/templates/project`) without their labels.
- ([#19381](https://github.com/rstudio/rstudio/issues/19381)): [Accessibility] Fixed an issue where screen readers announced the custom CA bundle path field in Publishing options, and the environment variable list in the Publish dialog, without a label.
- ([#19381](https://github.com/rstudio/rstudio/issues/19381)): [Accessibility] Fixed an issue where screen readers announced the list in the dialog for choosing a Posit Connect Cloud account without a label.
- ([#19435](https://github.com/rstudio/rstudio/issues/19435)): Fixed an issue where `renv.lock` and other text files with an unrecognized extension could not be opened in the source editor ("File is binary rather than text") on hosts without the `file` utility. `.lock` files are now recognized as text, and when `file` is missing or fails the file's contents are inspected instead.
