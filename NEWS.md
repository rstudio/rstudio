## RStudio 2026.12.0 "Parrot Balsam" Release Notes

### New
- ([#19108](https://github.com/rstudio/rstudio/issues/19108)): Application warnings now appear in separate rows, each with its own action and dismiss button. Dismissed messages stay dismissed when reconnecting to the session.
- ([#19403](https://github.com/rstudio/rstudio/issues/19403)): On macOS, RStudio now offers to become the default application for R files, since Xcode otherwise claims `.R` files; the Global Options > General > Advanced pane also has a button for this.
- ([#17173](https://github.com/rstudio/rstudio/issues/17173)): Open-source RStudio Desktop on macOS and Windows can now download an available update in the background and install it on restart ("Install and Restart"), instead of sending you to the download page. Administrators can keep the notification but turn off in-app installation with the `RSTUDIO_DISABLE_IN_APP_UPDATES` environment variable.
- ([#12622](https://github.com/rstudio/rstudio/issues/12622)): RStudio Desktop's offers to switch to the version of R a project asks for, and to run `renv::restore()` for a project whose renv library is empty, now appear in the Console instead of a bar at the top of the window. When the requested version is not installed, the folder it is installed into can be confirmed or changed before the installation starts, and a nearby installed version is offered as an alternative.
- ([#2846](https://github.com/rstudio/rstudio/issues/2846)): The editor's status bar now counts the Git changes in a file, says which one the cursor is on, and has buttons to step through them, and each file in the Git pane has a button that opens it at its first change.
- ([#19208](https://github.com/rstudio/rstudio/issues/19208)): Show Changes Side by Side is now also a toggle on the editor toolbar. Headers name the two sides (before: the index; after: the working tree), and clicking a change marker offers to revert that change.
- ([#19241](https://github.com/rstudio/rstudio/issues/19241)): The Console notice shown at startup when RStudio reduces background file operations for a project can now be turned off with the `show_reduced_file_operations_notice` preference (e.g. from the Command Palette), or for all users by an administrator with `"show_reduced_file_operations_notice": false` in `rstudio-prefs.json`.
- ([#19555](https://github.com/rstudio/rstudio/issues/19555)): The branch filter in the History view of the Review Changes window now has a search box, and searches in the Git branch menus now ignore case.
- ([#19661](https://github.com/rstudio/rstudio/issues/19661)): RStudio Desktop can now switch to another installed version of R on macOS and Linux as well as Windows, from Tools > Global Options > General or Session > Switch R Version, restarting only the R session rather than RStudio. The version of R switched to, including from the renv R version notice in the Console, is kept for later launches; it takes precedence over `RSTUDIO_WHICH_R` until that variable changes (as it does when rig's default R changes), and is forgotten then. If the chosen R can't be used at startup, RStudio starts with the default R and asks whether to keep the choice (on Windows, the Choose R dialog is shown, as before), and if a session fails to start with the chosen R, the error page offers to go back to the previous or the default version of R.

### Fixed
- ([#19772](https://github.com/rstudio/rstudio/issues/19772)): Fixed an issue where Posit Assistant, reading the Console's contents, saw a long line of output containing non-ASCII characters as several lines, and could see part of an escape sequence in such a line (e.g. the target of a hyperlink) as text.
- ([#19769](https://github.com/rstudio/rstudio/issues/19769)): Fixed an issue where Posit Assistant reading the Console's contents processed the Console's whole scrollback on each request, holding up console output while it did. With a large scrollback limit (Tools > Global Options > Console > Maximum lines of output to keep in the console) each request could take seconds; the time taken now depends on the number of lines skipped and requested.
- ([#19736](https://github.com/rstudio/rstudio/issues/19736)): Fixed an issue where, with S7 1.0.0, the R session stopped responding and had to be terminated when an S7 generic was printed while one of its methods had a breakpoint set.
- ([#19728](https://github.com/rstudio/rstudio/issues/19728)): Fixed an issue where RStudio Desktop on macOS could stop responding to clicks, beeping as though a dialog were open with none visible, after showing a message such as "Update Available" while another application was active. The message now opens on an RStudio window instead of as a separate alert.
- ([#19703](https://github.com/rstudio/rstudio/issues/19703)): Fixed an issue where R code run by Posit Assistant kept running past the time limit Posit Assistant set for it, holding the Console busy (indefinitely, for code that never finished) after Posit Assistant had reported the call as timed out. The code is now interrupted when its time limit passes, and code still waiting for the Console when its time limit passes is not run.
- ([#19718](https://github.com/rstudio/rstudio/issues/19718)): Fixed an issue where interrupting R code run by Posit Assistant (e.g. with Escape) just as it finished could leave some of the checks Posit Assistant places on file access applied to code run afterwards in the Console.
- ([#19687](https://github.com/rstudio/rstudio/issues/19687)): Fixed an issue on Windows where `savehistory()` and `loadhistory()` showed no error when they could not save or load the history file, e.g. because its folder did not exist.
- ([#19694](https://github.com/rstudio/rstudio/issues/19694)): Fixed an issue where an R section header whose trailing run of `#` matched its leading run, such as `#### Load data ####`, lost its heading level, so the document outline showed the sections beneath it at the same level instead of nested under it, and hierarchical section folding did not fold them away with it. Since 2026.09.0 such a header had been treated as a decorative banner; it now nests by its leading `#` run like any other section header. Headers drawn as bars with no label, or with a leading run deeper than `######`, still carry no heading level.
- ([#19690](https://github.com/rstudio/rstudio/issues/19690)): Fixed an issue where the R session crashed at startup when `R_HISTSIZE` was 0 and a `.Rhistory` file existed, and failed to start when `R_HISTSIZE` was negative. As in R, `R_HISTSIZE` now limits only the number of commands saved to the history file (on quit and by `savehistory()`), read when the file is saved; it no longer limits the commands kept during the session. The session keeps the most recent 512 commands, or more if `R_HISTSIZE` is larger when it starts, and the history file can't hold more than the session kept. Negative or invalid values are ignored.
- ([#19686](https://github.com/rstudio/rstudio/issues/19686)): Fixed an issue where a `loadhistory()` call that failed, e.g. because the file didn't exist, discarded the session's command history. With "Always save history" on, quitting the session then replaced `.Rhistory` with only the commands run after the failed call.
- ([#19654](https://github.com/rstudio/rstudio/issues/19654)): Fixed an issue where a chunk's output, restored when reopening an R Markdown or Quarto document, was missing all of the text shown before an error with a traceback, when text written to standard error (e.g. with `cat(file = stderr())`) came right before the error. In chunks with `error = TRUE`, each error box now shows its own error's message, and text printed after an error box has appeared is shown below it, rather than in the text above it.
- ([#19684](https://github.com/rstudio/rstudio/issues/19684)): Fixed an issue on Windows with R 4.1 and earlier where `savehistory()` and `loadhistory()` did not save or load the history file, and showed no error, when given a path starting with `~` and the home directory contained non-ASCII characters, such as `é` on an English-language system.
- ([#19647](https://github.com/rstudio/rstudio/issues/19647)): Fixed an issue where RStudio Desktop installed from the RPM on Fedora 45 could not start an R session, failing with "error while loading shared libraries: libssl.so.3". The RStudio Desktop and RStudio Server RPMs now require the OpenSSL libraries they were built with, so installing them on a system that has moved to a newer OpenSSL also installs the older one (on Fedora 45, `openssl3-libs`).
- ([#19674](https://github.com/rstudio/rstudio/issues/19674)): Fixed an issue where File > New File commands (e.g. New R Script) did nothing, and showed no error, when RStudio failed to create the document. An error message is now shown.
- ([#18924](https://github.com/rstudio/rstudio/issues/18924)): Fixed more issues with malformed ANSI escape sequences in console output: text after an unterminated sequence at the end of an error message, a prompt, or the output of inline R code is no longer dropped; such text shown at the next prompt is no longer made part of the message or warning before it; and a color sequence with an unknown format or an unsupported sub-parameter (e.g. `ESC[38;3;1m` or `ESC[38;4:3;1m`) no longer resets the colors and styles in effect.
- ([#10086](https://github.com/rstudio/rstudio/issues/10086)): Fixed an issue where moving the mouse between the "Show Traceback" and "Rerun with Debug" links on a Console error made them flicker.
- ([#19645](https://github.com/rstudio/rstudio/issues/19645)): Fixed an issue where the "Show Traceback" link on a Console error did not change to "Hide Traceback" while the traceback was shown.
- ([#19680](https://github.com/rstudio/rstudio/issues/19680)): Fixed an issue where Windows Smart App Control could block the RStudio Desktop installer and uninstaller.
- ([#19631](https://github.com/rstudio/rstudio/issues/19631)): Fixed an issue where the RStudio Desktop installer on Windows showed its Welcome page a second time after the User Account Control prompt when installing for all users.
- ([#19624](https://github.com/rstudio/rstudio/issues/19624)): Fixed an issue where installing or updating Posit Assistant failed when the computer's hostname contained a non-ASCII character such as an accented letter. On macOS the error was "Illegal byte sequence"; on Windows with R 4.1 or earlier, it said the downloaded package declared a blank version.
- ([#19614](https://github.com/rstudio/rstudio/issues/19614)): Fixed an issue where, with an AI assistant selected (Posit AI, the default, or GitHub Copilot), the code completion popup and function signature tooltip on the first lines of the Source editor opened above the line, over the editor toolbar and tabs, the popup sometimes with its top cut off by the edge of the window. They now open below the line when they don't fit above it within the editor, the popup with the best match first.
- ([#19620](https://github.com/rstudio/rstudio/issues/19620)): The R logo in the Console header is now easier to see with dark themes: the R is a lighter blue, and a gap separates it from the ring.
- ([#19593](https://github.com/rstudio/rstudio/issues/19593)): Fixed an issue where a horizontal scrollbar flickered below the file list while a narrow Files pane was being made narrower.
- ([#19579](https://github.com/rstudio/rstudio/issues/19579)): Fixed an issue where Show Changes Side by Side could open with its two sides out of step when lines had been removed above the lines in view, and could scroll away from the line being viewed when a change above it was staged or unstaged.
- ([#4572](https://github.com/rstudio/rstudio/issues/4572)): Fixed an issue on Linux desktop where pasting a file copied in a file manager such as Nautilus or Nemo inserted nothing into the editor, the Console, or the visual editor, instead of the file's path. This was a regression in RStudio 2026.08.
- ([#12235](https://github.com/rstudio/rstudio/issues/12235)): Fixed an issue where RStudio Desktop took about 4 seconds longer to start a second session (e.g. with Session > New Session) than the first. The "Initializing R" page now shows its text right away instead of only the R logo, and the "Cannot Connect to R" and "Error Starting R" pages no longer have a blank Retry button, blank headings, or a missing exit code.
- ([#19576](https://github.com/rstudio/rstudio/issues/19576)): Fixed an issue where the close button of a Git change opened from the editor gutter could not be clicked in a document long enough to scroll when scrollbars take up no room (as macOS's overlay scrollbars do): the editor's scrollbar area covered it.
- ([#19590](https://github.com/rstudio/rstudio/issues/19590)): The New Project wizard now rejects an invalid package name (e.g. `test-cpp`) for the R Package using Rcpp, RcppArmadillo, RcppEigen, and devtools project types, instead of failing to create the project with an error such as "Malformed package name". The R Package project type also now rejects names R does not allow, such as `x` and `pkg.`.
- ([#19571](https://github.com/rstudio/rstudio/issues/19571)): Fixed an issue where To Source in the History pane could open a new R script instead of inserting into a document open in the visual editor. With the cursor outside a code chunk, the commands are now inserted as a new R code chunk at the cursor.
- ([#19566](https://github.com/rstudio/rstudio/issues/19566)): Fixed an issue where To Source in the History pane appeared to do nothing when the document was in the visual editor with the cursor in a code chunk. The commands were inserted out of sight, elsewhere in the document, and written to the file on the next save; they are now inserted into the chunk.
- ([#19578](https://github.com/rstudio/rstudio/issues/19578)): Fixed an issue where turning off Show Changes Side by Side could scroll the editor away from the line being viewed, often to the end of the document, when lines had been removed above it.
- ([#19580](https://github.com/rstudio/rstudio/issues/19580)): RStudio no longer warns that R 4.6.2 is newer than the maximum version of R it was tested with.
- ([#9477](https://github.com/rstudio/rstudio/issues/9477)): The spelling dictionary archives downloaded when building RStudio and when installing additional languages now have dates in their file names, so a future dictionary update no longer replaces a file that packagers have pinned by checksum.
- ([#19559](https://github.com/rstudio/rstudio/issues/19559)): Fixed an issue where C/C++ code completion, diagnostics, and navigation stopped working in Rcpp and cpp11 source files compiled as C++20 or newer (the default as of R 4.6), most visibly on Linux. A precompiled header that can't be loaded is now rebuilt, and files are parsed without it in the meantime.
- ([#17025](https://github.com/rstudio/rstudio/issues/17025)): Posit Assistant and GitHub Copilot no longer exit immediately on startup when `http_proxy` or `https_proxy` is set without a URL scheme (e.g. `proxy.example.com:8080`), a form R accepts.
- ([#19512](https://github.com/rstudio/rstudio/issues/19512)): Fixed an issue on Windows where an R installation recorded in the registry under a path containing non-ASCII characters was not found at startup or listed in the R version chooser.
- ([#19218](https://github.com/rstudio/rstudio/issues/19218)): Reduced the time spent computing Git change markers for large replacements, while keeping change boundaries consistent when opening side-by-side review.
- ([#19496](https://github.com/rstudio/rstudio/issues/19496)): Fixed an issue where RStudio Desktop would not start, and showed no error, when its desktop options file (`config.json` in the user data directory) had been truncated or otherwise corrupted, e.g. by a crash while it was being written. The damaged file is now moved aside, desktop options are reset to their defaults, and RStudio says where the file was moved.
- ([#19499](https://github.com/rstudio/rstudio/issues/19499)): RStudio Desktop now reports when an R installation was found but failed to start, naming the R and showing its exit status and error output, instead of claiming that no R installation could be located. The R chooser on Windows shows the same details when a selected R fails to load.
- ([#19480](https://github.com/rstudio/rstudio/issues/19480)): Fixed an issue where the SQL Results pane could stay empty the first time it showed a SQL preview, when its data grid took more than a moment to load. The preview also no longer disappears when another Console tab (e.g. Terminal, Render, Background Jobs) is shown or hidden.
- ([#19493](https://github.com/rstudio/rstudio/issues/19493)): Fixed an issue where the Files pane could delete the directory it was showing: pressing Space with the grid focused selected the hidden `..` row, and Delete then removed the parent directory. The parent row can no longer be selected, and the session refuses to delete the home directory, the working directory, the project directory, the directory shown in the Files pane, or any directory containing them.
- ([#18861](https://github.com/rstudio/rstudio/issues/18861)): Fixed issues with uploading files from the Files pane: uploads larger than 1 MB occasionally failed with "Error occurred while executing method", uploads into a folder whose path contains a double quote failed, and choosing OK without picking a file offered to overwrite the target folder instead of asking for a file. A failed upload also no longer leaks memory in the R session or leaves a partial file behind.

- ([#18959](https://github.com/rstudio/rstudio/issues/18959)): Web file dialogs now report an error and stay in the current folder when a typed folder cannot be opened, instead of silently switching to the project or home folder and completing a pending Save, Open, or Choose there.
- ([#19098](https://github.com/rstudio/rstudio/issues/19098)): Fixed an issue where `rstudio <file>` in the Terminal pane could launch another Desktop instance after a shell startup file reset `PATH`.
- ([#19249](https://github.com/rstudio/rstudio/issues/19249)): Fixed an issue where All in the editor's Find/Replace bar ignored the Regex option and selected literal matches instead. With Whole word, a regex with alternatives such as `foo|bar` now bounds every alternative in Find Next, All, and Replace All.

- ([#18386](https://github.com/rstudio/rstudio/issues/18386)): Improved terminal recovery when a WebSocket stops responding, and prevented callbacks from an old connection from interrupting a replacement connection.
- ([#15965](https://github.com/rstudio/rstudio/issues/15965)): Fixed several issues that prevented building with `-DRSTUDIO_USE_SYSTEM_DEPENDENCIES=ON`, where Hunspell, RapidJSON, utf8cpp, GTest and libgit2 were not found or not linked. Thanks to [@Flamefire](https://github.com/Flamefire).

- ([#19386](https://github.com/rstudio/rstudio/issues/19386)): Fixed an issue where the Terminal's right-click menu on Windows and Linux Desktop listed Ctrl+C and Ctrl+V for Copy and Paste, which the terminal sends to the shell, instead of Ctrl+Shift+C and Ctrl+Shift+V.
