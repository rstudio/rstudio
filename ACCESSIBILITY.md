# Accessibility

RStudio is working toward conformance with [WCAG 2.2](https://www.w3.org/TR/WCAG22/) Level AA. Known gaps are documented in our Accessibility Conformance Reports (ACRs), available at https://posit.co/accessibility.

## Tracking progress

- Merged accessibility improvements: [pull requests labeled `accessibility`](https://github.com/rstudio/rstudio/pulls?q=is%3Apr+is%3Amerged+label%3Aaccessibility)
- The [RStudio release notes](https://docs.posit.co/ide/news/) prefix accessibility-related fixes and features with "[Accessibility]".

## Reporting accessibility issues

Before opening a new issue, please search [existing accessibility issues](https://github.com/rstudio/rstudio/issues?q=is%3Aissue+state%3Aopen+label%3Aaccessibility).

When opening an issue, include "accessibility" in the title or description so maintainers can label it, and if possible include:

- RStudio version and edition (Desktop or Server)
- Operating system, and browser if applicable
- Assistive technology and version (e.g., NVDA 2025.1, VoiceOver, JAWS)
- Steps to reproduce, and expected vs. actual behavior

For general questions, contact [accessibility@posit.co](mailto:accessibility@posit.co).
